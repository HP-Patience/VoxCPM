# TTS-VoxCPM 参考音频配音

## 输入与默认行为

需要要朗读的目标文本，允许直接粘贴或提供 UTF-8 文本文件。未指定参考音频时，默认使用用户已指定的 `C:\Users\wjx\Downloads\采访录音 1.wav`，无需再次询问声音来源；本次明确指定其他录音时优先使用新录音。缺少目标文本时只询问文本；选定录音不存在或不可读时，询问有效路径，不擅自换声音。本次提供多个录音而未明确选择时，先澄清。

默认沿用已验证的本地方式：VoxCPM2、CUDA、仅参考音频克隆、10 推理步、CFG 2、关闭编译优化、关闭额外降噪和文本规范化。不自动转写参考音频或加载 SenseVoice。每段 seed 从 42 依次增加，段间停顿 0.3 秒。这些是本机稳定起点，不是普遍最佳配置；遵从用户明确指定的参数。

- 保存原始目标文本，不擅自润色、删减、翻译或替换数学字母。需要读音改写时先确认并另存朗读稿，保留原稿。
- 默认参考音频模式不要求参考文本。仅在用户要求极致克隆且提供准确转写时使用 `--prompt-file`；参考转写不是目标文本。不要捏造转写。
- 音频路径使用上述默认值或本次用户明确指定的值，运行时显式传给 `--reference`；不要复用其他历史录音、把个人录音复制进 skill、或未经授权上传到外部服务。

## 本机已知环境（运行前验证仍存在）

- 项目：`C:\Users\wjx\Desktop\TTS\VoxCPM`
- Conda：`F:\conda\Scripts\conda.exe`，环境：`TTS_voxcpm`
- 本地模型：`C:\Users\wjx\Desktop\TTS\VoxCPM\pretrained_models\VoxCPM2`

用此环境运行 [scripts/generate.py](scripts/generate.py)，不要另建环境或重复下载模型。路径不存在时检查实际安装位置。此脚本直接调用本地 Python SDK，不依赖网页 API。

## 运行流程

1. 验证输入可读，检查录音时长/采样率、GPU、剩余内存以及 17860 对应进程。已有服务可能已经加载模型；不要同时加载第二份 GPU 模型。
2. 已有服务在生成时，不自动打断。若需要停掉空闲的 VoxCPM 服务，先告知用户影响，并核对 PID、命令行和端口确实属于本项目；不杀其他 Python 进程或其他应用。若无法确定是否空闲，询问用户是否停止。不要自动改 Windows 分页文件或重启电脑。
3. 为本次任务建立独立输出目录，如项目 `outputs/<任务名>-<本地时间>/`。把原稿保存为 UTF-8 `input.txt`。先执行 `--dry-run`，检查分段重组未漏字、参数、参考音频信息。脚本内部保留空白段落边界用于切分，段内换行折为空格。
4. 使用下方命令执行。脚本每次只加载一份模型，按句子/段落切分；超长句继续按逗号等切分，必要时硬切，默认每段最多 110 字符。先观察第一段成功，再继续等待整批。需要先让用户试听再决定时可加 `--limit 1`；去掉该参数后续跑。
5. 查看实际进程输出及 `status.json`，按阶段报告完成段数，不把 Gradio 预计时间当超时，不用网站 HTTP 200 当作生成成功。通过工具等待实际任务完成；不要只启动进程就宣称完成。
6. 返回完整 WAV 的绝对路径音频预览，说明时长、使用模式及实际参数，保留分段和清单。如果停止了原来的网页服务，任务结束后在不重复加载模型的前提下恢复原启动配置，并确认端口；不要为了恢复网页而重新跑测试生成。

### PowerShell 示例

把文本和输出目录占位符替换为实际路径；参考音频默认使用下方路径，用户指定其他录音时替换 `--reference`。

```powershell
$env:TORCH_COMPILE_DISABLE = '1'
$env:PYTHONUNBUFFERED = '1'
$env:PYTHONIOENCODING = 'utf-8'
& 'F:\conda\Scripts\conda.exe' run --no-capture-output -n TTS_voxcpm python -u `
  'C:\Users\wjx\.codex\skills\tts-voxcpm-narration\scripts\generate.py' `
  --model-path 'C:\Users\wjx\Desktop\TTS\VoxCPM\pretrained_models\VoxCPM2' `
  --reference 'C:\Users\wjx\Downloads\采访录音 1.wav' `
  --text-file 'C:\路径\input.txt' `
  --output-dir 'C:\路径\本次输出' `
  --device cuda --steps 10 --cfg 2 --seed 42 --max-chars 110 --gap 0.3
```

所有参数和选项可用 `--help` 查看。默认不降噪；用户明确需要时加 `--denoise`。不要把 `--denoise` 误说成禁用降噪。脚本不提供编译优化开关，默认 `optimize=False`。

## 断点续跑与失败边界

- 同一输出目录用相同命令续跑，已通过校验的分段会跳过。输入、模型标识或生成参数变化时拒绝复用旧缓存，改用新输出目录。不要删掉已生成成果来“修复”续跑。
- `manifest.json` 保存输入哈希/参数/分段；`segments.json` 保存每段时长、文件哈希和边界；`status.json` 保存进度；`generation-stderr.log` 保存诊断。`.generation.lock` 防止同目录同时写入。若崩溃遗留锁，先核对记录的进程已结束，才移除这个锁文件。
- 遇到 os error 1455、CUDA OOM、模型加载错误时，停止批次并保留分段，说明尚未完成。检查内存和重复模型；不要无休止重试、升级依赖、改系统设置或承诺已修好。解决资源原因后才重试。
- 生成结束检查段数齐全、音频可读/非空/有限数值、采样率一致、拼接帧数符合分段加停顿。脚本会执行这些检查，但不能证明逐字发音正确。没有实际听过就不要声称“音色一致、无漏读”；数学变量、人名等提醒用户重点试听。
